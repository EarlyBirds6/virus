# VIRUS — Landing Page

A single-page, static landing page for the VIRUS meme-token concept.

## Deploy on Vercel

No build step is required.

### Option 1 — Vercel dashboard
1. Upload this folder/repository to GitHub.
2. Import the repository into Vercel.
3. Framework preset: **Other** (or leave auto-detected).
4. Build command: **None**
5. Output directory: **.**
6. Deploy.

### Option 2 — Vercel CLI
From this folder:

    npx vercel

The page intentionally contains no live token contract, wallet connection, API, market data, or Twitter URL yet. Replace the classified/TBA placeholders when those details are ready.
